## Build

```bash
cd senal-streamvault
./gradlew :app:assembleRelease
# APK: app/build/outputs/apk/release/
```

## Uso

Al abrir: Welcome → Setup Provider → M3U / Xtream / Stalker → sync → Live / Movies / Series.
